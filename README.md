# Evolution_Item_Trader
A mod for Pokémon Mystery Dungeon: Origins that adds an evolution item shop to the Base Camp. Evolution items can be bought and sold for Heart Scales. The shop can be accessed on the Release Candidate by clearing a new dungeon and boss.
This mod was developed by FlowerSnek and Fieryfenix.
